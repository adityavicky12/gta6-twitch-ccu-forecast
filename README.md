Forecasts GTA VI's launch-day Twitch viewers hour by hour: it learns the shape of a big console launch day from the case's own comparable launches and anchors that shape to hour 1's print.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
